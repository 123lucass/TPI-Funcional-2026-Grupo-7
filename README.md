## 🚦 Descripción del Proyecto

Sistema de control lógico para semáforos inteligentes implementado en Common Lisp bajo el paradigma funcional puro. El sistema modela estados de transición, temporización automática, auditoría forense, análisis de ciclos y distribución temporal, aplicando inmutabilidad absoluta, cero bucles imperativos y funciones puras.

---

## ▶️ Cómo ejecutar

1. Tener instalado **SBCL** y **Quicklisp**
2. Clonar el repositorio:
```bash
git clone https://github.com/123lucass/TPI-Funcional-2026-Grupo-7.git
```
3. Cargar el sistema:
```bash
sbcl --load lisp/core.lisp
```
